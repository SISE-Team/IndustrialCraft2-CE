# Behavioral reference inputs

This tree contains retired energy reference code, historical generators and source asset authoring data. No path here belongs to a production or verification Java source set. The complete decompilation and original input JAR are local development inputs outside the source checkout.

Runtime ownership is recorded separately in `validation/rewrite-ownership.json`; moving or renaming these files contributes no implementation rewrite coverage. Gradle builds the engine, API and NeoForge modules and packages the delivered assets from `assets/src/main/resources`.
